This repo is a demo built on the Conversations API starter. Follow the starter's rules in
[AGENTS.md](https://github.com/moveworks/conversations-api-starter/blob/main/AGENTS.md). The
[Conversations API documentation](https://docs.moveworks.com/api-reference/conversations-api) is the source of truth for API behavior.
API calls and message display helpers belong in the starter's `moveworks_capi` library, not here. Polish lives in the optional modules
(see "Design choices" in README.md), and `python -m pytest` must pass offline.
